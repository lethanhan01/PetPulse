# PetPulse

Giao diện web PetPulse được xây dựng bằng React, TypeScript, Vite và Tailwind CSS.

## Yêu cầu

- [Node.js](https://nodejs.org/) 20 trở lên (khuyến nghị bản LTS)
- npm (được cài kèm Node.js)

## Chạy dự án trên máy local

1. Mở terminal tại thư mục dự án:

   ```bash
   cd PetPulse
   ```

2. Cài đặt các thư viện phụ thuộc:

   ```bash
   npm install
   ```

3. Khởi động môi trường phát triển:

   ```bash
   npm run dev
   ```

4. Mở địa chỉ mà Vite hiển thị trong terminal, thông thường là [http://localhost:5173](http://localhost:5173).

Nhấn `Ctrl + C` trong terminal để dừng máy chủ phát triển.

## Tạo bản build production

```bash
npm run build
```

Lệnh này tạo các tệp triển khai trong thư mục `dist/`.
